# プレゼン用 起動手順（URLを `http://securitylabND:8000/` にする）

ブラウザのアドレスバーを `127.0.0.1:8000` ではなく **`http://securitylabND:8000/`** と表示させる手順です。
どのPC・どの置き場所でも使えます（プロジェクトの場所は問いません）。

## しくみ
- `127.0.0.1` の代わりに好きな名前を表示する → Windows の hosts ファイルで名前を `127.0.0.1` に割り当てる

## 前提
- このプロジェクト一式があること（フォルダ名・置き場所は自由）
- Python が使えること（`.venv` があればそれを使う。無ければシステムの Python）
- `ALLOWED_HOSTS` に `securitylabND` が登録済みであること（`config/settings.py`。登録済み）

---

## 手順

### 1. hosts ファイルに名前を追加（1回だけ・管理者）
1. スタートで「メモ帳」を検索 → 右クリック →「**管理者として実行**」
2. メモ帳で次のファイルを開く（ファイルの種類を「すべてのファイル」にする）
   `C:\Windows\System32\drivers\etc\hosts`
3. 最終行に次の1行を追加して保存

   ```
   127.0.0.1   securitylabND
   ```

### 2. VSCode でプロジェクトを開く
1. VSCode を起動 →「**ファイル → フォルダーを開く**」でプロジェクトフォルダを選ぶ
   （またはフォルダを右クリック →「**Codeで開く**」）
2. ターミナルを開く：メニュー「**ターミナル → 新しいターミナル**」（ショートカット `Ctrl + @`）
   - ターミナルは自動でプロジェクトフォルダの場所で開くので、`cd` は不要
3. （初回のみ・推奨）Python を `.venv` に合わせる
   - `Ctrl + Shift + P` → `Python: Select Interpreter` → `.venv` の Python を選ぶ
   - 以降、ターミナルの行頭に `(.venv)` と表示される

### 3. サーバーを起動
VSCode のターミナルで実行する。

- インタープリタを `.venv` にした場合（行頭に `(.venv)` が出ている）

   ```
   python manage.py runserver 127.0.0.1:8000
   ```

- `(.venv)` が出ていない／手動で指定する場合

   ```
   .\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000
   ```

- 停止するときは、ターミナルで **Ctrl + C**

### 4. ブラウザで開く
- アドレスバーに **`http://securitylabND:8000/`** と入力
- `127.0.0.1` の代わりに `securitylabND` が表示されれば成功
- 「保護されていない通信」表示はローカル HTTP なので問題なし

---

## 後片付け（必要なら）
- プレゼン後に元へ戻す場合は、hosts に追加した `127.0.0.1 securitylabND` の行を削除する

---

## 名前を変えたい場合（任意）
`securitylabND` 以外の名前にしたいときは、2か所を同じ名前にそろえる。

1. hosts の行（手順1）を新しい名前に変更
2. `config/settings.py` の `ALLOWED_HOSTS` に新しい名前を追加
   - ブラウザは名前を小文字で送ることがあるため、**大文字そのまま**と**全部小文字**の両方を入れておくと安全
   - 例：`ALLOWED_HOSTS = ["127.0.0.1", "localhost", "MyDemo", "mydemo"]`

---

## メモ
- この手順は「プレゼン表示用」。通常の開発・配布は `127.0.0.1:8000` のままでよい。
- 通常起動（配布用）は同梱の `start.bat` をダブルクリック。
