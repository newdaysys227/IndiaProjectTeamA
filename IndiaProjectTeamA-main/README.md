# Web Security Academy（学習用・対策前後の比較教材）

PortSwigger の Web Security Academy で扱われる代表的なWeb脆弱性を題材に、
各テーマの「対策前（脆弱）」と「対策後（安全）」を **並べて比較** しながら学べる
Django 製の教材サイトです。問題文・画面・データはすべて自作です。

> ⚠️ **重要**：このサイトは学習目的で *意図的に安全でない実装* を含みます。
> 必ずローカル（`127.0.0.1`）でのみ実行し、インターネットへは絶対に公開しないでください。

## 収録ラボ（9テーマ）

| # | カテゴリ | 内容 |
|---|----------|------|
| 1 | SQLインジェクション | 検索機能での文字列連結による注入 |
| 2 | XSS（反射型） | 検索キーワードの未エスケープ出力 |
| 3 | XSS（格納型） | コメント保存・表示での未エスケープ |
| 4 | CSRF | メール変更フォームのトークン欠如 |
| 5 | 認証 | ユーザー名列挙・総当たり |
| 6 | パストラバーサル | ファイル名連結による領域外読み出し |
| 7 | OSコマンドインジェクション | shell連結（安全なシミュレータで再現） |
| 8 | アクセス制御（IDOR） | 所有者チェックの欠如 |
| 9 | ファイルアップロード | 拡張子・ファイル名の未検証 |

各ラボの詳細ページで「脆弱性の説明 / 攻撃のゴール / 対策前後のデモ / コード差分 / 対策ポイント」を確認できます。

## かんたん起動（Windows・おすすめ）

1. `prezen.zip` を右クリック →「すべて展開」で解凍する。
2. 中の **`start.bat` をダブルクリック** する。
3. 自動でライブラリ導入・DB作成・データ投入まで行い、ブラウザで
   http://127.0.0.1:8000/ が開きます。

※ 事前に Python（3.10以上）が必要です。未インストールなら https://www.python.org/ から入れてください
（インストール時に「Add Python to PATH」にチェック）。

## 手動セットアップ

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py seed          # デモ用データ投入
python manage.py runserver 127.0.0.1:8000
```

ブラウザで http://127.0.0.1:8000/ を開いてください。

## メモ

- 「対策前」ページは差し替え前提の仮実装です（画面上に🚧の注記があります）。
- OSコマンドインジェクションのラボは、安全のため実際のOSコマンドは実行せず、
  挙動を再現するシミュレータになっています。
- `python manage.py seed` を再実行すると商品・ユーザー・口座が初期化されます。
